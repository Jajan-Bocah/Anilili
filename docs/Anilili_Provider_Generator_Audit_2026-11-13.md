# Audit Repository Anilili Provider JSON Generator

**Tanggal audit:** 13 November 2026  
**Sumber:** ZIP yang diunggah pengguna, `Anilili-Provider-Generator.zip` (14.320 entri; termasuk `.git`, `node_modules`, `coverage`, dan `dist`).  
**Referensi eksternal:** `Jajan-Bocah/Anilili`, branch `feature/hybrid-remote-provider-engine`, commit `8c6230665699978963aa3e77dd791ceaced94219`.  
**Kesimpulan:** **BELUM FEATURE-COMPLETE / BELUM RELEASE-READY**. Code library dan tes ada, tetapi wizard belum lengkap, ada masalah integrasi/validasi dan risiko keamanan.

## P0 — Blokir penyelesaian fitur utama

1. **Tiga wizard step masih placeholder.** `src/App.jsx:153-163` merender `PlaceholderStep` pada `upload`, `analyze`, dan `generate`; `src/components/PlaceholderStep.jsx:11` secara literal menampilkan “Langkah ini akan diimplementasikan pada fase berikutnya.” `inferredRules` di `src/App.jsx:36` tidak pernah memperoleh hasil analisis. **Tindakan:** Implementasikan komponen Upload Samples, Analyze, Generate; sambungkan state dan file kelompok Search, Detail/Episodes, Watch/Stream (+ Homepage/HAR opsional). Pastikan multiple samples dan URL asal disimpan dalam project, dengan parser yang dipilih berdasarkan format file.
2. **Pipeline parser/analyzer belum digunakan UI.** `inferRules` tidak diimpor oleh halaman mana pun; `parseHar`, `parseMhtml`, dan kedua Web Worker hanya dipanggil dalam kode library/tes. Bukti: pencarian simbol di `src/`. **Tindakan:** implementasikan orchestration `upload → sanitize → parse → analyze → edit → generate → test → export` dan progres/error state per file/kelompok. HAR perlu integrasi rule discovery untuk permintaan AJAX/dynamic content.
3. **Halaman Export mengubah state ketika render.** `src/pages/Export.jsx:15-33` sudah menggunakan `useEffect(generate)`, tetapi `src/pages/Export.jsx:72` **masih memanggil `generate()` tanpa syarat saat render**. Fungsi `generate()` memanggil `setProviderJson`/`setReport`; pada proyek valid, ini berpotensi menyebabkan loop render/error React. **Tindakan:** hapus pemanggilan baris 72 dan buat render derivasi yang murni; tambah tes UI dengan proyek valid.
4. **Mismatch workflow `stream` vs `sources`.** `src/components/RuleEditor.jsx:77-99` mengeluarkan workflow `stream`; `src/lib/generator/providerGenerator.js:107-110` hanya mengekspor `search`, `episodes`, `servers`, `sources`. **Tindakan:** map `stream` ke `sources`, pastikan hasil mapping cocok domain parser Android, dan tulis tes ekspor untuk kasus ini.
5. **WorkflowBuilder belum mampu membentuk workflow operasional lengkap secara terarah.** `src/components/WorkflowBuilder.jsx:10-20` hanya memberi beberapa parameter dan tak mengedit `output.type` + `output.mapping`; `src/components/RuleEditor.jsx:88-98` membuat step `select` saja tanpa fetch/input; `src/lib/generator/providerGenerator.js:122-127` default output `RAW` tanpa pemetaan domain. **Tindakan:** editor wajib mendukung input/context, HTTP method/query/header yang aman, JSON nested params, output mapping dan preview per step, bukan hanya “valid op”.
6. **Validasi workflow sangat dangkal.** `src/lib/contract/engineContract.js:458-483` hanya memeriksa nama op dan `${...}` pada beberapa parameter; tidak mewajibkan params sesuai op, input, output mapping, ataupun saveAs. **Tindakan:** per-op validators dan e2e fixture tests yang membuktikan output `Search → Episodes → Servers → Sources` dapat diterjemahkan oleh Android runtime.
7. **Kontrak URL salah di UI.** `src/pages/CreateProject.jsx:69-81` melabeli `endpoint` sebagai URL `provider.json`; `src/lib/generator/providerGenerator.js:73-98` menyamakan `providers[].endpoint` dan `metadata.sourceUrl`. Di contoh Anilili terbaru, `providers[].endpoint` adalah base situs (misalnya `https://anichin.moe/`), sementara `metadata.sourceUrl` adalah URL file konfigurasi (`https://anichin.moe/provider.json`). **Tindakan:** dua field terpisah dan validasi/trust sesuai masing-masing.

## P1 — State dan integrasi

8. **Proyek belum persisten.** `src/lib/db/projectStore.js` mempunyai CRUD, namun tidak dipakai dalam aplikasi (`src/App.jsx`). Refresh akan menghilangkan state kerja. **Tindakan:** save/load/delete/restore IndexedDB dengan schema version, termasuk metadata sample sanitized.
9. **Impor/ekspor proyek tidak seimbang.** `src/pages/Export.jsx:47-61` mengimpor JSON objek arbitrer, tetapi tidak ada tombol ekspor project bundle atau `test-report.json`; `tests/integration/flow.test.js:84-92` menguji JSON round-trip **provider.json**, bukan project bundle. **Tindakan:** format project bundle yang versioned, validasi input impor, ekspor bundle dan test report, tes round-trip project real.
10. **Test Center tidak mengonsumsi sampel pengguna.** `src/pages/TestCenter.jsx:39-48,65,90-101` menggunakan HTML demo embedded yang sama untuk semua workflow. HTTP step bukan replay fixture HAR yang sebenarnya. **Tindakan:** pilih fixture per workflow dan step; offline replay HAR/HTML/MHTML, tunjukkan NOT_TESTED/NOT_DETECTED vs PASSED dengan benar. Simpan hasil test untuk report ekspor.
11. **Live Test saat ini hanya melakukan GET endpoint**, bukan menjalankan `Search`, `Episodes`, `Servers`, `Sources` (`src/pages/TestCenter.jsx:112-128`). Status `livePassed` memakai `liveResult.ok` (`:159`), yang hanya menunjukkan HTTP response berhasil. **Tindakan:** label “HTTP probe passed” (bukan provider live passed), atau implementasi live workflow executor yang dibatasi secara aman.
12. **State editor rentan tertimpa.** `src/pages/ReviewRules.jsx:10,26-29` memakai workflow lokal; `src/components/WorkflowBuilder.jsx:37-40,113-116` menyinkronkan props dan memancarkan state ke parent lewat effects. Hindari siklus sinkronisasi, preservasi edit manual saat rule inference berubah, dan parent callback yang berubah setiap render. Pastikan tes UI nyata memverifikasi perubahan bertahan saat pindah wizard dan impor proyek.
13. **Form “Simpan dan Lanjut” tidak berpindah step** (`src/pages/CreateProject.jsx:19-29` hanya memanggil `onChange`; `src/App.jsx:149-152` tidak menavigasi). Navigasi header `Berikutnya` tidak memvalidasi kelengkapan step. **Tindakan:** per-step guards dan auto-navigation yang sesuai.
14. **Status kompatibilitas keliru.** `src/lib/contract/engineContract.js:111-153` masih mengategorikan `output-parse-stubs`, `extract-output-tostring`, dan `no-identifier-injection` sebagai critical, padahal commit Android terbaru telah mengimplementasikan output parser, typed extraction, serta injeksi/cache slug. `src/lib/generator/providerGenerator.js:249-253` memberi status `JSON_VALID` bahkan ketika struktur invalid. **Tindakan:** klasifikasi blocker berbasis bukti yang terbaru, status `INVALID` eksplisit, jangan berikan `ANILILI_READY` tanpa Android runtime + playback evidence.

## P0 — Keamanan dan deployment

15. **HAR sanitasi tidak menyeluruh (TERBUKTI).** `src/lib/parsers/harParser.js:215-232` mempertahankan `request.url` dan `response.content` mentah; `:250-280` juga memasukkan URL mentah ke ringkasan API/media/redirect. Uji lokal dengan token sintetis pada query dan response body: **token tetap ditemukan dalam output**. **Tindakan:** sanitasi menyeluruh sebelum return/persistence/UI/export, termasuk raw URL query, response content, redirect URL, cookies dan payload; fail-closed/redact unknown credential fields. Tambah regression tests yang melakukan string search sentinel di seluruh hasil serialisasi.
16. **Worker tidak memverifikasi Access JWT di kode.** `worker/index.js:113-139` hanya fail-closed pada allowlist kosong; dengan allowlist terisi, request tanpa Access JWT dapat memicu upstream fetch **bila route tidak dilindungi oleh Cloudflare Access**. Terbukti dengan pemanggilan lokal `worker.fetch()` + mocked `fetch` (HTTP 200, upstream called). **Tindakan:** pastikan Cloudflare Access policy benar-benar melindungi route, idealnya validasi JWT pada Worker; uji bypass origin/alternate host/path. Jangan klaim aman tanpa deployment policy verification.
17. **SSRF dan rate limit belum hardened.** `worker/index.js:14,46-58` tidak memblokir seluruh reserved ranges/IPv6 varieties; uji `0.0.0.0`, `100.64.0.1`, `198.18.0.1`, IPv4-mapped IPv6 menghasilkan false; `:16-44` rate limit hanya `Map` per isolate; `:21-26` fallback percaya `x-forwarded-for`. **Tindakan:** ketatkan target validation, server-side allowlist, redirect check, Cloudflare native rate limiting dan perlindungan lintas isolate. Periksa fitur DNS/platform SSRF aktual. Fail closed sampai mitigasi.
18. **Response size cap bukan streaming.** `worker/index.js:281-288` membaca seluruh `response.arrayBuffer()` sebelum membatasi 1 MB, sehingga batas tidak mencegah alokasi besar. `:275` membatalkan timeout sebelum pembacaan body. `:146-156` pemeriksaan ukuran request berbasis `Content-Length` saja. **Tindakan:** streaming reader dengan cap byte dan abort controller selama pembacaan, request body cap yang tidak hanya percaya content-length; batas JSON/buffer output.
19. **Konfigurasi Wrangler tidak mengikuti Workers Static Assets.** `wrangler.toml:2` mengarahkan `main` ke `dist/index.html` (HTML, bukan entrypoint JS); `:15-16` memakai `[[pages.functions]]` yang bukan konfigurasi routing Worker Static Assets. Dokumentasi Cloudflare Workers mensyaratkan `[assets] directory = "./dist"` dan, bila ada script, `main = "./worker/index.js"`, dengan penanganan route `/api/*` melalui Worker. **Tindakan:** pisahkan/static+API routing yang benar, `run_worker_first` untuk `/api/*`, asset fallback, test `wrangler dev` serta deployment dry-run. Lihat https://developers.cloudflare.com/workers/static-assets/binding/ .
20. **Live Test tetap OFF sampai P0 keamanan beres.** Validasi fitur secara lokal dengan fixture boleh dilakukan; jangan aktifkan Worker publik hanya karena security unit tests kecil lulus.

## P2 — UI/UX dan pengujian

21. Alur wizard belum dapat digunakan lengkap; buat loading/error/empty/success states **pada halaman nyata**, bukan placeholder. Perbaiki responsif 375px, overflow stepper dan toolbar, WCAG AA, input labels, keyboard/assistive technology.
22. Tambah browser-level integration/e2e tests (Playwright/RTL) untuk seluruh wizard, bukan hanya utilitas pure JS. Tes `tests/integration/flow.test.js` saat ini 6 tes yang tidak merender komponen UI. Tambah import/export bundle tests, multi-fixture analyzer tests, Kotlin parity fixtures, Worker security fetch tests.
23. `memory/implementation-progress.md` tidak akurat menyebut fase 0–7 selesai, dan menyebut `generate()` sudah dipindah ke useEffect padahal masih dipanggil saat render. Perbaiki dokumentasi setelah tes nyata.
24. Git ZIP memakai branch `master` dengan satu initial commit `d688633` (`AWAL`); sebagian besar proyek masih **untracked** di Git snapshot. **Jangan** jalankan `git clean -fdx`, `git reset --hard`, atau tindakan destruktif lain tanpa backup/persetujuan. `.git` dan `node_modules` disertakan secara sengaja.

- ✅ File ZIP berhasil dibaca; source, tes, docs, worker dan Git history diperiksa.
- ✅ `node --check` atas seluruh `*.js` di `src/` dan `worker/` tidak menghasilkan error.
- ✅ ESLint dijalankan langsung dari `node_modules`: **0 error / 63 warning**.
- ✅ Tes statis: `src/App.jsx` menampilkan placeholder 3 langkah, dan bundle dist mengandung pesan tersebut.

- ✅ Uji runtime fungsi `parseHar` menunjukkan token sintetis masih muncul dalam serialized result.
- ✅ Uji runtime Worker dengan mock `fetch` menunjukkan request tanpa JWT diteruskan saat allowlist diatur (jika tidak terlindungi Cloudflare Access).
- ✅ `git status` dan commit diperiksa.
- ⚠️ Vitest/build **tidak dapat dijalankan ulang dalam environment Linux ini** memakai paket `node_modules` dari ZIP Windows. Error: `Cannot find module @rollup/rollup-linux-x64-gnu`. Percobaan instalasi dependency Linux tidak berhasil (tidak tersedia lewat koneksi runtime). Laporan angka 162 passed di `docs/COMPATIBILITY_REPORT.md` **adalah klaim agent**, bukan hasil verifikasi ulang.
- ⚠️ Pengujian Chrome headless via localhost terhalang kebijakan `ERR_BLOCKED_BY_ADMINISTRATOR`. Pengujian fungsional website nyata dan live Worker deployment belum dilakukan.
